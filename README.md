# Пороги переработки

Инструмент для переработки ресурсов в Albion Online:

- **Цены по городам** — самый дешёвый лот и лучший ордер на закупку в каждом королевском городе, возраст цены, график средней цены за 7/30 дней.
- **Выгодность переработки** — все ресурсы и тиры T4–T8: где купить сырьё и материал прошлого тира, где продать, себестоимость, прибыль на штуку и на стак, маржа, объём продаж.
- **Пороги** — до какой цены покупать сырьё и материал и ниже какой цены не продавать, чтобы переработка шла в плюс. Для камня — пороги зачарованного камня.

Данные — [Albion Online Data Project](https://www.albion-online-data.com/), запросы идут прямо из браузера. Сервер не нужен: сайт работает на GitHub Pages.

Настройки (возврат ресурсов, налоги, станция, маржа, запас на уценку) и введённые цены хранятся в браузере.

Файлы: `index.html` — разметка, `styles.css` — оформление, `app.js` — загрузка данных и расчёты.

Не связано с Sandbox Interactive.
