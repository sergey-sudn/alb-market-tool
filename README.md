# Пороги переработки

Инструмент для переработки ресурсов в Albion Online:

- **Цены по городам** — самый дешёвый лот и лучший ордер на закупку в каждом городе, возраст цены. Виджеты для выбранного предмета: где купить дешевле всего, где продать дороже, динамика за 7 дней и перепродажа между городами.
- **Переработка** — все ресурсы и тиры T4–T8: где купить сырьё и материал тира ниже, где продать, прибыль на штуку и на стак, маржа, ликвидность. Виджеты «Лучшее прямо сейчас», «Лучшие по марже», «Больше всего за стак».
- **Пороги** — до какой цены покупать и от какой продавать, чтобы переработка шла в плюс; шпаргалка для чата и расчёт закупки на заданный бюджет.
- **Журнал сделок** — записи «купил / переработал / продал», собранные в циклы, с реальной прибылью рядом с прогнозом. Хранится в браузере, выгружается в файл.

Две темы: тёмная и светлая. На телефоне — карточки вместо таблиц, нижняя панель разделов и фильтры в шторке.

Данные — [Albion Online Data Project](https://www.albion-online-data.com/), запросы идут прямо из браузера. Иконки предметов — `render.albiononline.com`. Сервер не нужен: сайт работает на GitHub Pages.

Настройки (возврат ресурсов, ежедневный бонус, налоги, станция, маржа, запас на уценку), введённые цены и журнал хранятся в браузере.

Файлы: `index.html` — разметка, `styles.css` — оформление, `app.js` — загрузка данных и расчёты, `names.js` — русские названия ресурсов, `images/cities/` — фоны городов.

Иконки и изображения городов принадлежат Sandbox Interactive. Сайт не связан с Sandbox Interactive.
